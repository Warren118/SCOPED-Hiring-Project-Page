# SCOPED-Hiring Project Page

Static React/Vite implementation of the SCOPED-Hiring project page.

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

Vercel should use `npm run build` with `dist` as the output directory. The page has no server-side dependencies, environment variables, database, or API routes.
